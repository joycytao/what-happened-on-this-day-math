# Perspective Carousel Template

Reusable 1080×1350 carousel for a parenting, homeschool, or learning perspective.

Default sequence: lifestyle hook → context/problem → perspective → practical shift → saveable takeaway → CTA. Use complete thoughts, real evidence where supplied, and a caption with relevant hashtags. Do not expose student information or make unsupported learning claims.

The design contract is migrated; rendering remains content-dependent until an authored slide source is supplied. The generator exits clearly rather than producing a misleading placeholder.
