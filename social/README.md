# Social templates

This directory contains reusable source templates for Instagram carousel formats.

- `learning-system-carousel-template/`: learning-system slide generator and assets.
- `clean-worksheet-carousel-template/`: clean worksheet carousel scaffold.
- `perspective-carousel-template/`: design contract for perspective-sharing carousel content.
- `product-carousel-template/`: product-carousel contract and routing notes.

The monthly content workstreams remain the source of authored content. These folders define reusable presentation systems and their expected inputs.
