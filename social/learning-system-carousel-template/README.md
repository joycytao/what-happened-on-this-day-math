# Learning System Carousel Template

Six-slide, 1080×1350 reusable template for `SAVE → ANALYZE → PERSONALIZE` learning-system content.

The migrated authoring source uses the shared cream/beige/navy system, lifestyle cover, context card, three-step system, worksheet evidence, blurred setup, and `SYSTEM` CTA. Keep the original source material private and redact identifying information.

Build entry point: `node scripts/generate-learning-system-carousel.mjs`.
