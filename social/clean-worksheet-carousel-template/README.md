# Clean Worksheet Carousel Template

Six-slide, 1080×1350 reusable template for `PRESERVE → CLEAN → REUSE` worksheet cleanup content.

Use a lifestyle hook, problem, prompt, result, blurred exact-prompt reveal, and `CLEAN` CTA. Share the approved visual system with the learning-system Carousel while keeping the narrative and CTA separate.

Build entry point: `node scripts/generate-clean-worksheet-carousel.mjs`.
