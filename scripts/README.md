# Social generation entry points

These commands are the stable entry points for the reusable social templates:

- `generate-learning-system-carousel.mjs`
- `generate-clean-worksheet-carousel.mjs`
- `generate-perspective-carousel.mjs`
- `generate-product-carousel.mjs`
- `build-product-reel.mjs`
- `build-campaign-reels.sh`

The wrappers preserve the existing monthly workstream generators where those already exist. A wrapper may report that authored source content is required when a template is intentionally a design contract rather than a complete renderer.
