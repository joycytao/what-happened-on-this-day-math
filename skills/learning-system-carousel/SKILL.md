# From Worksheets to a Weekly Learning System

Use this skill for the reusable six-slide series named **From Worksheets to a Weekly Learning System**. It is a peer workflow to `clean-worksheet-carousel`; both workflows are active, reusable, and intentionally different.

Choose this workflow when the post explains how a parent saves worksheets and tests, uses AI to analyze patterns, and creates personalized practice. Choose `clean-worksheet-carousel` when the post's primary offer is a clean worksheet prompt.

## Core narrative

1. Cover: a parent encounters a stack of worksheets or tests.
2. Context: useful evidence has no reliable place.
3. System: `SAVE → ANALYZE → PERSONALIZE`.
4. Result: readable worksheet details plus a progress snapshot.
5. Setup: a blurred reusable workflow with a centered lock.
6. CTA: follow and comment `SYSTEM`.

## Output contract

- Six English PNGs, exactly `1080 × 1350 px` / 4:5.
- Editable source: `template.html`, `carousel.css`, and `content.js`.
- Canonical upload set: `output/final/`.
- Caption package: `output/caption.md`.
- Upload the six PNGs together; do not upload HTML to Instagram.

## Fixed design system

- Account: `@engineermom.afterhours`.
- Palette: background `#F6F0E2`, ink `#203245`, beige `#D8C6B2`.
- Safe area: 96 px outer margin.
- Header and page number appear on every slide.
- Only Slide 1 uses a lifestyle image. Slides 2–6 use the cream field and information modules.
- Headline font: Avenir Next Demi Bold; metadata: Verdana; supporting copy: Georgia.
- Keep headlines to two lines and body copy concise for mobile reading.

## Slide rules

### Slide 1 — Lifestyle Cover

Use one weekly lifestyle scene. A worksheet, test, folder, planner, or pencil may support the story but must not become the primary close-up. Change only the Cover image, eyebrow, and hook.

### Slide 2 — Context

Use a pure cream field and one large rounded context card. Do not use a worksheet close-up. The approved direction is:

```text
THE MATERIAL IS GOOD.
THE SYSTEM NEEDS A PLACE.
```

The card explains that worksheets and tests hold useful patterns but are easy to lose after grading.

### Slide 3 — The System

Use three equal cards:

- `01 SAVE`: pills `SCANNER`, `CAMERA`.
- `02 ANALYZE`: pills `Claude`, `Gemini`, `ChatGPT`.
- `03 PERSONALIZE`: pills `Claude`, `Gemini`, `ChatGPT`.

Use text pills instead of generated official logos so the assets remain accurate and reusable.

### Slide 4 — The Result

Use two large worksheet detail crops, not three tiny full pages:

- Page 01 middle: place value and multiplicative relationships.
- Page 02 upper: computation questions; exclude the Name area.

Crop-to-fill the intended visual region. Do not leave transparent letterboxing. Remove worksheet frame lines and shadow; use only a subtle softened edge. Keep dashboard padding equal on all sides. Example metrics: Place values 92%, Basic operation 88%, Multiplicative 75%, Understanding / word problem 60%. Mark presentation values as illustrative until verified.

### Slide 5 — System Setup

Use a large rounded card with a blurred workflow and a centered, high-contrast lock. The visible structure is `COLLECT → ANALYZE → PERSONALIZE → REVIEW`. Keep actual setup details unreadable. Use `#203245` for the lock body, `#D8C6B2` for the shackle, and `#F6F0E2` for the keyhole.

### Slide 6 — CTA

Use the circular back-view portrait. Keep `SYSTEM` consistent everywhere:

- `WANT THE LEARNING SYSTEM?`
- `Step 1: Follow @engineermom.afterhours`
- `Step 2: Comment "SYSTEM"`
- `LEAVE A COMMENT: "SYSTEM"`
- `I'll send the system setup in DM.`

Only promise DM delivery when the creator has a manual or automated delivery workflow ready.

## Reusable inputs

Change only:

- `content.js > cover.image`, `cover.eyebrow`, and `cover.hook`.
- Worksheet detail assets when the weekly evidence changes.
- Dashboard values after verifying the underlying analysis.

Never expose a child's name, school, teacher, student number, or other personal information. Prefer readable detail crops over tiny full pages.

## Verification checklist

Before handoff, confirm:

3. Slide numbering is 01/06 through 06/06.
