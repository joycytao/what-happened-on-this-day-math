# Clean Worksheet Carousel

Use this workflow for the clean-worksheet-prompt campaign. It shares the parent project assets, template, palette, and account identity with `learning-system-carousel`, but has its own content architecture and CTA.

## Output contract

- Authoring source: shared `template.html`, `carousel.css`, and `content.js`.
- Instagram output: six separate PNGs, each exactly 1080×1350 px.
- Social copy output: `output/caption.md`.
- Account label: `@engineermom.afterhours`.
- Language: English.

## Fixed slide system

1. Lifestyle Cover / Hook — weekly scene changes; used worksheet is only a secondary clue.
2. The Problem — explain why answers, marks, and notes make reuse difficult.
3. The Prompt — explain Preserve → Clean → Reuse in three cards.
4. The Result — show the clean worksheet as the dominant visual and the marked source as secondary.
5. The Exact Prompt — blur the full prompt body and use `FOLLOW + SAVE FOR THE PROMPT`.
6. CTA — use the supplied portrait and ask viewers to comment `CLEAN`.

## Fixed visual system

- Background: `#F6F0E2`.
- Ink: `#203245`.
- Beige: `#D8C6B2`.
- Outer margin: 96 px.
- Keep the shared header, page number, typography, card geometry, and CTA position fixed.

## Privacy and visual rules

- Blur or exclude child name, school, teacher, student number, and other identifying data.
- Prefer a readable question crop over a tiny full-page comparison.
- Never expose the complete prompt when the intended design is a blurred reveal.
- Only promise DM delivery when the delivery workflow is ready.

## Workflow selection

Choose this skill when the post's primary offer is a clean worksheet prompt. Choose `learning-system-carousel` when the post explains how a parent saves worksheets and tests, analyzes patterns, and creates personalized practice. The two workflows share project assets but do not replace one another.
