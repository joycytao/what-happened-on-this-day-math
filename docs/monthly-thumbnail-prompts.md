# Monthly Thumbnail Production Prompts

These are the canonical prompts for the four monthly thumbnail assets. They are
derived from the exact prompts supplied in PR #77 comments. The attached
reference image is authoritative for layout and visual style; this document
does not authorize redesigning the template.

## Shared production rules

Use the attached reference image as the exact layout and visual-style reference.
For every asset, preserve:

- square `1260×1260` canvas;
- warm ivory background `#FEFFEF`;
- deep navy typography `#2B313F`;
- bright orange accent `#FF8A00`;
- thin rounded orange border;
- bold geometric sans-serif typography;
- minimal editorial, teacher-friendly visual language;
- generous whitespace;
- small centered 6pm Studio logo at the bottom;
- thin orange horizontal lines framing the bottom logo.

The PDF is the source of truth. Any worksheet preview must be rendered from
the final `[MONTH]` PDF and may only be scaled or cropped. Never invent,
redraw, rewrite, or generate worksheet content.

All four assets must remain part of the same reusable 12-month family. Keep
the layout, colors, typography hierarchy, borders, spacing, logo placement,
and footer treatment unchanged across months. Only replace the month-specific
worksheet pages and optional month-specific doodle/accent.

## Thumbnail 1 — Cover

```text
- thin rounded orange border
- centered editorial composition
- bold geometric sans-serif typography
- generous whitespace
- small 6pm Studio logo centered at the bottom
- thin orange horizontal line aligned with the bottom logo
- simple, minimal, teacher-friendly visual language

Replace only the month-specific content:

Main headline:
[MONTH]

Product title:
MORNING WORK MATH

Supporting text:
31 DAILY WORD PROBLEMS

Place the month name as the largest text near the top.
Place “MORNING WORK MATH” directly below it.
Place the supporting line beneath the title.
Place one large, simple, hand-drawn orange line-art doodle in the center.

Below the pumpkin, place a centered `3 LEVELS` block with one orange horizontal
line on each side. Keep this block closer to the pumpkin than to the bottom
logo. Extend the bottom orange lines toward the centered logo and keep the logo
small and clear inside the footer.

The center doodle must represent:
[MONTH DOODLE]

The doodle must be simple, recognizable, orange single-line artwork,
elementary-education appropriate, visually balanced, and consistent in scale
and position across all months. Use a large bold geometric sans-serif month
headline, a smaller single-line product title, regular-weight supporting text,
and the vertical hierarchy `MONTH → PRODUCT TITLE → SUPPORTING TEXT → DOODLE →
3 LEVELS → FOOTER`. Change only the month name and central doodle; do not
redesign the layout.
```

## Thumbnail 2 — What's Included

```text
Create a square 1260×1260 product thumbnail for a printable monthly math worksheet packet.

Use the attached reference image as the exact layout and visual-style reference.

Headline:
WHAT’S INCLUDED

Layout:
- Place “WHAT’S INCLUDED” in large, bold, navy uppercase text at the top center.
- Add three small orange hand-drawn emphasis lines on each side of the headline.
- Arrange five real worksheet page previews in a structured grid.
- Top row: STORY, LEVEL 1, LEVEL 2.
- Bottom row: LEVEL 3, ANSWER KEY.
- Give every page preview a thin rounded orange border.
- Add a bright orange rounded label pill beneath every page.
- Use subtle soft shadows behind the page previews.
- Keep the layout balanced, symmetrical, and spacious.
- Keep the bottom logo and horizontal lines separate from the bottom labels.

Worksheet source requirements:
- Use actual worksheet pages rendered from the final [MONTH] PDF.
- Preserve actual worksheet text, math problems, answer key, page layout,
  colors, and logos.
- Only scale and crop real PDF page renders.
- Use the manifest page numbers for STORY, LEVEL 1, LEVEL 2, LEVEL 3, and
  ANSWER KEY.
```

Negative prompt:

```text
No fake worksheet screenshots. No AI-generated worksheet text. No invented math
problems. No altered answer key. No missing page labels. No people. No
classroom scene. No calendar icon. No photographic background. No gradients.
No complex illustrations. No extra text. No distorted worksheet pages. No
changed color palette. No asymmetrical layout. No oversized logo. No overlapping
cards, labels, or footer.
```
