# Utility Reels Workflow Plan

## Purpose

Create a repeatable three-week Utility Reel series that shows how a parent can
turn a completed school math test into a structured review routine:

```text
Completed test → Clean review copy → Error analysis → Targeted practice
```

The Utility Reel introduces a useful learning workflow rather than making the
monthly TPT package the main subject. Product Reels explain what 6PM Studio
sells; Utility Reels show how 6PM Studio helps families work with real
learning evidence.

## Audience and promise

**Primary audience:** Parents or caregivers helping an elementary-school child
review a completed math test at home.

**Viewer promise:** A completed test can become a practical next-step review
routine instead of being looked at once and forgotten.

**Tone:** Calm, practical, privacy-aware, and encouraging. Do not frame the
workflow as replacing a teacher's judgment or as proof of a child's overall
ability.

## The three-week cycle

Each cycle uses one completed and graded math test, followed by one new review
worksheet generated from high-confidence error categories. Start a new cycle
when a new completed test is available; do not repeat the same source forever.

### Week 1 — Recover: create a clean review copy

**Learning problem:** The child already wrote on the test, so the original page
is not available for independent re-practice.

**Transformation:** Completed school test → clean blank review page.

**Suggested hook:**

> Your child brought home a completed math test. Here is how to turn it into a clean review page.

**Shot plan:**

1. Show a completed test with correct and incorrect responses.
2. Blur or crop all names, school information, teacher information, dates, and
   other identifying details.
3. Show the cleanup or reconstruction step.
4. Reveal the clean blank review page.
5. Show the child attempting the page again, if a staged or consented visual is
   available. Otherwise show the clean page only.

**CTA options:**

- `Save this for the next test review.`
- `Follow for simple at-home math review workflows.`

### Week 2 — Understand: identify the skills behind the mistakes

**Learning problem:** Counting wrong answers does not explain which math skill
needs more practice.

**Transformation:** Completed school test → high-confidence error categories →
review suggestions.

**Suggested hook:**

> Do not just count the wrong answers. Find the math skill behind them.

**Shot plan:**

1. Reuse the same completed-test setup from Week 1.
2. Show the test being scanned or uploaded.
3. Show an analysis dashboard grouped by broad math skill.
4. Highlight one or two high-confidence categories.
5. Show a short review recommendation for each highlighted category.

**CTA options:**

- `Save this before your next review session.`
- `Use the mistakes to decide what to practice next.`

**Evidence rule:** Only display categories supported by clear evidence on the
provided test. If an answer or grading mark is unclear, show it as uncertain or
exclude it from the formal weak-area summary. One test should not be presented
as a complete assessment of the child's math ability.

### Week 3 — Practice: generate targeted review

**Learning problem:** Knowing the weak area is useful only if it leads to a
specific next practice step.

**Transformation:** High-confidence error categories → new worksheet targeting
the same skills with new problems.

**Suggested prompt:**

> Based on the high-confidence errors from this week's worksheet, create a short review worksheet targeting the same math skills with new numbers and new problems.

**Suggested hook:**

> Your child missed a few questions. Now create practice for the skill behind them.

**Shot plan:**

1. Show several completed worksheet pages with correct and incorrect responses.
2. Show the selected high-confidence error categories from the Week 2 analysis.
3. Show the prompt being entered.
4. Reveal the newly generated review worksheet.
5. Show the new worksheet being prepared for the next practice session.

**CTA options:**

- `Save this workflow for the next review session.`
- `Practice the skill—not just the same question.`

**Generation rule:** The new worksheet should target the identified skill
categories with new values or new problem contexts. It should not merely copy
the child's original answers or expose the answer key.

## Repeatable production workflow

For each new completed test:

1. **Select the source** — use one explicitly provided completed and graded math
   test.
2. **Protect privacy** — redact the child's name, school, teacher, student ID,
   dates if identifying, and any other personal information before recording.
3. **Create Week 1 assets** — produce a clean review copy while preserving the
   original questions, diagrams, numbering, and answer spaces.
4. **Create Week 2 assets** — analyze only visible, high-confidence evidence and
   capture the resulting categories and recommendations.
5. **Create Week 3 assets** — use the Week 2 categories as the input for a new
   targeted worksheet.
6. **Record the three Reels** — keep the source test visually consistent so the
   audience can recognize the same learning case across the cycle.
7. **Publish in sequence** — Week 1 first, Week 2 second, and Week 3 third.
8. **Review metrics** — record reach, saves, shares, profile visits, follows,
   and link clicks separately for each week.
9. **Start the next cycle** — use a new completed test when available.

## Asset and safety checklist

Before publishing any Reel:

- The source document is the user's or family's document, or the creator has
  permission to show it.
- All personal information is removed or blurred.
- The original completed test is not overwritten.
- Printed questions are kept separate from handwritten answers, grading marks,
  and teacher comments during cleanup.
- Unreadable answers or marks are not presented as confirmed errors.
- The Reel does not claim that one test proves mastery or a permanent weak area.
- The generated worksheet is reviewed for mathematical correctness and layout
  before it is shown publicly.
- The answer key is not shown unless its public-display status has been
  explicitly confirmed.

## Relationship to the other content types

| Content type | Primary job | Typical CTA |
| --- | --- | --- |
| Product Reel | Help viewers understand the monthly package | View the full package on TPT |
| Utility Reel | Help viewers discover a useful review workflow | Save or follow |
| Carousel | Help viewers inspect and compare the product | Save and view the product |
| Note to Followers | Build an ongoing relationship | Reply with feedback |
| Discount | Help interested viewers decide to purchase | Shop during the offer |

The Utility Reel should not force a product pitch into every post. A natural
connection can appear in the caption or profile link after the workflow has
provided value.

## Measurement plan

Track the three weeks as one cycle, while judging each Reel by its primary job:

- **Week 1:** saves, shares, profile visits
- **Week 2:** saves, comments, follows, profile visits
- **Week 3:** saves, profile visits, link clicks

Do not judge the Utility series only by immediate TPT sales. Its first job is to
make the account discoverable and useful; product content and the product page
handle the later conversion step.

## Current capability assumptions to verify

These are implementation gates, not claims that the current tools already
support every step:

1. The cleanup workflow can reliably create a blank page from a completed test
   while preserving the original printed content and layout.
2. The analysis workflow can produce a dashboard or report from the explicitly
   supplied test and distinguish high-confidence findings from uncertain ones.
3. The generation workflow can create new practice problems from the selected
   skill categories without copying the original test or inventing unsupported
   conclusions.

If any gate is not supported, the Reel should show the supported manual or
partial workflow rather than imply an automated result that has not been
verified.
